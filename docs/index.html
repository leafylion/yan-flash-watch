PHASE 1

바리바리 루인가 ばりばりルインガ

탱버스터 (90도 부채꼴 범위)

1회차는 어그로 1위, 2회차는 어그로 2위에게 온다.

신들의 상 (1회차) 神々の像（1回目）— 디버프 전달 수정판

  1. 탱힐 또는 딜러에게 선이 붙고, 그 뒤 상(像)으로부터 넉백이 발생한다.
  2. 블리자가 + 파이가의 진짜/가짜 장판 (산개인지 쉐어인지 주의) ※ 산개는 상하 반전
  3. 상으로부터 탱힐 2명 + 딜러 2명, 총 4명에게 빔이 오므로 가로 일렬로 선다. (빔을 받은 위치가 타워 출현 위치가 됨)
  4. 빔을 받지 않은 사람이 타워에 들어간다.
  5. 「츠기츠기 트랩(차례차례 트랩)」 시전이 끝나면 랜덤으로 2명(탱힐 1명·딜러 1명)에게 디버프가 붙는다.
    0초에 자기 중심으로 폭발하므로, 디버프 전달을 위해 동·서로 나눠 쉐어로 처리한다.
    디버프 보유자는 바깥에서 안쪽으로 날아가도록 한다.
  6. 그 후 「수수께끼 매직(なぞなぞマジック)」이 오므로 케프카의 진짜/가짜를 확인하고 기믹 처리.

신들의 상 (2회차) 神々の像（2回目）— 디버프 전달 수정판 + 중력탄

전원에게 선이 붙는다.

  • 상을 봤을 때 오른쪽 아래(노랑) → 남쪽에서 쉐어 처리 후 각자 산개
  • 상을 봤을 때 왼쪽 위(보라) → 남쪽에서 쉐어 처리 후 중앙으로

바리바리 루인가(탱 스위치? 무적이면 사고가 적을 듯)와 함께 반갈 장판이 오므로 상의 이펙트를 확인.

다시 전원에게 선이 붙는다. 산개는 상하 반전 → 반갈 장판.

디버프를 전달하기 위해 서쪽에 탱힐 / 동쪽에 딜러가 대기하고, 넉백으로 그라비가(중력탄)에 맞는다.
디버프 보유자는 뒤따라 늪(沼)에 들어간다.

PHASE 2

종말의 두 팔 終末の双腕

탱버스터 (2인 공동 탱킹 전제).

미싱 (최신) ①ミッシング最新권장

규칙

  1. 페어 고정 (MT·H1 / ST·H2 / D1·D3 / D2·D4) ※ 미싱 전에 서쪽=탱힐 / 동쪽=딜러로 나눠두면 식별하기 쉬움
  2. 쉐어가 붙은 페어는 1·2·3·8회차 / 그 외 페어는 4·5·6·7회차에 처리
  3. 1회차부터 규칙에 따라, 쉐어 대상은 우선순위 순으로 타워에 들어감 (탱힐은 왼쪽 타워, 딜러는 오른쪽 타워)
  4. 홀수 회차의 왼쪽은 부채꼴, 오른쪽은 원형
  5. 타워 안 우선순위: H1 > H2 > MT > ST > D1 > D2 > D3 > D4
  6. 타워 밖은 위치 고정 (왼쪽 TH, 오른쪽 D)
  7. 과거·미래 분신 유도 → 부채꼴 담당 + 근접
  8. 3회차 타워 처리 후 자신에게 원형이 붙은 경우 /mk stop <me> ※ 깜빡 방지

과거의 종언 / 미래의 종언 過去の終焉 / 未来の終焉

  • 과거의 종언: 장판이 터진 뒤, 타워 사이에서 「소멸의 다리(消滅の脚)」 시전 시작까지 대기.
  • 미래의 종언: 장판이 터진 뒤, 타워 반대편에서 「소멸의 다리」 시전 시작까지 대기 → 시전이 보이면 타워 쪽으로 달려 들어감.
  • 4회차 과거·미래는 A에 집합하여 「소멸의 다리」를 기믹에 맞춰 회피.

PHASE 3

재구축 & 결전 再構築&決戦

케프카가 카오스와 엑스데스를 소환한 뒤, 보스로부터 가까운 사람에게 라이트 파티(4인 2조)로 나누는 디버프를 부여.

미리 자리잡기: 카오스 쪽 MT·H1·D1·D3 / 엑스데스 쪽 ST·H2·D2·D4

바울 오브 아고니 バウル・オブ・アゴニー

전체 공격 후 혼돈의 불 · 혼돈의 물 · 혼돈의 바람(정면 받기 / 배면 받기) 디버프가 부여되고, 필드에 불 · 물 · 바람 이펙트가 출현.

이펙트는 반드시 바람을 사이에 두고 물과 불이 배치되며(불·물의 위치가 바뀌는 경우도 있음), 필드 마커로 치면 숫자 방향에 출현한다. 또한 불과 물은 반드시 대각으로 생성되고, 바람의 대각에는 아무것도 없도록 배치된다.

디버프 / 이펙트 정리

  • 혼돈의 바람 … 넉백을 받아 해제하는 디버프. 정면 또는 배면에서 넉백을 받는 2종류가 있음. 아래의 불·물을 가진 사람은 서로 불·물을 맞혀 해제하고, 해당 디버프가 없는 사람은 기믹 마지막의 진공파로 해제.
  • 혼돈의 불 … 2명에게 랜덤 부여. 효과시간 종료 후 자기 중심 원형(AoE) 범위.
  • 혼돈의 물 … 2명에게 랜덤 부여. 효과시간 종료 후 도넛 범위. (불·물 디버프는 반드시 탱힐 2명·딜러 2명에게 랜덤 부여)
  • 불 이펙트 … 혼돈의 불 종료 후 가까운 2명에게 도넛 범위 발생. 이 범위를 혼돈의 물 보유자에게 맞혀 바람을 해제.
  • 물 이펙트 … 혼돈의 물 종료 후 가까운 2명에게 원형(AoE) 범위 발생. 이 범위를 혼돈의 불 보유자에게 맞혀 바람을 해제.
  • 바람 이펙트 … 혼돈의 바람을 해제하면 몇 초 후, 가까운 사람에게 쉐어 범위 공격.

불·물 디버프가 붙은 페어(혼돈조)와 남은 시간(초)을 확인한다.
이번 예시는 불 = MT·D3, 물 = H2·D4에 붙고, 불 쪽 시간이 더 짧다고 가정 (물이 더 짧은 경우도 있음).

  • ST는 엑스데스가 범위 선더가를 시전하므로, 시간이 짧은 디버프와 반대 이펙트 쪽으로 유도. (이번엔 불이 짧으므로 물 이펙트로 유도 — 불·물 이펙트는 반드시 대각으로 생성)
  • 불 이펙트를 1:1로 사이에 끼우듯 위치를 잡아 원형(AoE) → 도넛 범위를 발생시킨다.
  • 우선순위는 안쪽부터 MT > ST > H1 > H2 > D1 > D2 > D3 > D4
  • 이때 불 이펙트에서 발생하는 원형 범위에 물 대상자가 들어가 맞아 디버프를 해제 (해제 시 혼돈의 바람 방향에 주의).

어느 디버프도 없는 사람은 바람 이펙트를 유도.
탱힐이 메인 유도를 맡아 안쪽부터 MT > ST > H1 > H2, 이를 방해하지 않는 거리감으로 딜러가 쉐어에 참가. (딜러 우선순위는 안쪽부터 D1 > D2 > D3 > D4)

모든 상황에서 MT가 가장 안쪽인 이유: 카오스를 중앙에 고정해 바람 이펙트 중에도 때릴 수 있게 하기 위함.

기믹 종료 후 엑스데스가 탱버스터를 시전하므로 ST는 무적 권장.

카오스가 호리즌탈 임플로전 / 버티컬 임플로전을 시전하므로
MT는 남아 있는 2개 이펙트가 있는 쪽으로 카오스를 향하게 한다.
ST는 엑스데스를 중앙으로 유도해 둔다.

혼돈의 물 디버프로 도넛 → 원형(AoE) 범위가 발생하므로, 기존 불 디버프 보유자가 여기에 맞아 디버프를 해제 (방향 주의).
바람 이펙트도 동일하게 처리한다.

ST는 바람 이펙트에 겹치도록 엑스데스를 유도하고, MT는 카오스를 유도해 둔다.

D3는 카오스의 엄브럴 스매시를 바람 이펙트의 반대쪽으로 유도.
진공파가 오므로 디버프 보유자는 방향에 주의해 넉백을 받는다.
디버프가 없는 사람은 넉백 방지 스킬(암즈렝스 / 확정 시전)을 쓰고 엑스데스의 타깃 서클 밖에서 대기.
우선순위는 탱힐이 왼쪽에서 안쪽(奥)부터 MT → ST → H1 → H2, 딜러는 오른쪽에서 안쪽부터 D1 → D2 → D3 → D4.
