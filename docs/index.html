빈빈빈타 ビンビンビンタ

빈빈빈타는 케프카를 봐서 왼쪽 손(케프카의 오른손)을 올리는지, 오른쪽 손(케프카의 왼손)을 올리는지에 따라 롤 산개 또는 쉐어로 변화하는 기믹이다.

  • 케프카를 봐서 왼쪽 손(케프카의 오른손) 올림 → 쉐어
  • 케프카가 봐서 오른쪽 손(케프카의 왼손) 올림 → 롤 산개
🖼 이미지빈빈빈타 손 확인 패턴:
  • 왼쪽 이미지: 케프카가 (플레이어 시점에서) 왼손 올림 → 쉐어
  • 오른쪽 이미지: 케프카가 (플레이어 시점에서) 오른손 올림 → 롤 산개

  • 북서=MT·H1, 북동=ST·H2, 남서=D1·D3, 남동=D2·D4

쉐어 마커(착탄하라)가 붙으므로, 해당 롤은 중앙에서 쉐어로 처리한다.
