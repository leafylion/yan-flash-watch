빈빈빈타 びんびんビンタ

빈빈빈타는 케프카를 봐서 왼쪽 손(케프카의 오른손)을 올리는지, 오른쪽 손(케프카의 왼손)을 올리는지에 따라 롤 산개 또는 쉐어로 변화하는 기믹이다.

케프카를 봐서 왼쪽 손(케프카의 오른손) → 쉐어 케프카가 봐서 오른쪽 손(케프카의 왼손) → 롤 산개
🖼 이미지 (표 내)빈빈빈타 손 확인 패턴:
  • 왼쪽 이미지: 케프카가 (플레이어 시점에서) 왼손 올림 → 쉐어
  • 오른쪽 이미지: 케프카가 (플레이어 시점에서) 오른손 올림 → 롤 산개

블랙홀 1회차 ブラックホール1回目

빈빈빈타 후 엑스데스가 블랙홀을 발생시킨다.
블랙홀 1회차 1번째 선은 어택1이 가져간다.

2번째 선은 어택1과 어택2가 가져간다.
어택2는 1번째 선의 반대쪽에 있는 선을 취득한다(어택1이 가까운 선을 취득하기 때문).

2번째 선을 처리 후 바로 선더가가 오므로 주의.
탱커 이외의 멤버는 엑스데스에서 멀어지도록 한다.

선더가가 터진 뒤 케프카가 이동하므로 카오스의 다밍(랜덤 타겟)에 주의하면서,
케프카의 올린 손을 확인하여 안지로 이동하고, 쉐어 또는 롤 산개를 한다.
🖼 이미지 (표 내)블랙홀 1회차 처리 흐름 (2×2 테이블).
  • 좌상: 어택1 담당자가 케프카를 기준으로 시계 방향 우선 블랙홀 선을 취득하는 배치도. 남색 방패(탱크1·2) + 딜러 아이콘 + 스톱/바인드/어택 마커 아이콘 표시. 방위 A·B·C·D·1~4=방위 마커.
  • 우상: 어택1·어택2 동시 선 취득. 어택2는 어택1 반대쪽 블랙홀 선을 취득.
  • 좌하: 2번째 선 처리 후 선더가 주의. 탱커 외 멤버가 엑스데스에서 멀어진 배치도.
  • 우하: 선더가 후 케프카 손 방향 확인 → 안지 이동 + 쉐어/롤 산개 처리 배치도.

블랙홀 2회차 ブラックホール2回目

어택1·어택2·어택3이 케프카를 기준으로 시계 방향으로 선을 가져간다.

어택1이 바인드1에게 선을 넘겨준다.

어택2가 바인드2에게 선을 넘겨준다.

케프카가 이동하므로 카오스를 케프카를 향하거나 등지도록 유도한다.
필드를 분단하는 AoE를 발생시키므로 카오스와 케프카를 보고 안지를 판단한다.

그 후 엑스데스의 선더가가 오므로 탱커 이외는 엑스데스에서 멀어진다.

🖼 이미지 (표 내)블랙홀 2회차 처리 흐름.
  • 좌상: 어택1·2·3이 케프카를 기준으로 시계 방향 우선으로 블랙홀 선 취득. 방위 마커 표시.
  • 우상: 어택1→바인드1 선 교환 단계. 어택1이 바인드1 위치로 이동하여 선 전달.
  • 좌중: 어택2→바인드2 선 교환 단계.
  • 우중: 케프카 이동 + 다밍 이딕트(분단 AoE) 안지 이동 배치도.
  • 좌하: 선더가 후 탱커만 엑스데스 근처, 나머지 멀어진 배치도.

블랙홀 3회차 ブラックホール3回目

바인드1·바인드2·바인드3이 케프카를 기준으로 시계 방향으로 선을 가져간다.

바인드1이 스톱1에게 선을 넘겨준다.

바인드2가 스톱2에게 선을 넘겨준다.

케프카가 이동하므로 카오스를 케프카에 대해 45도로 향하게 한다.

케프카의 올린 손을 확인하여 안지로 이동하고, 쉐어 또는 롤 산개를 한다.
또한 이때 화이트홀이 오므로 HP를 전부 채워둔다.

🖼 이미지 (표 내)블랙홀 3회차 처리 흐름.
  • 좌상: 바인드1·2·3이 케프카를 기준으로 시계 방향 우선으로 블랙홀 선 취득. 방위 마커 표시.
  • 우상: 바인드1→스톱1 선 교환 단계.
  • 좌중: 바인드2→스톱2 선 교환 단계.
  • 우중: 케프카 이동 + 카오스를 케프카에 대해 45도 방향으로 유도 배치도.
  • 좌하: 빈빈빈타 손 방향 확인 → 안지 이동 + 화이트홀 HP 관리 타이밍.

블랙홀 4회차 ブラックホール4回目

스톱1과 스톱2가 케프카를 기준으로 시계 방향으로 선을 가져간다.

🖼 이미지 (표 내)블랙홀 4회차 처리 흐름.
  • 왼쪽: 스톱1·스톱2가 케프카를 기준으로 시계 방향 우선으로 블랙홀 선 취득. 방위 마커 표시.
  • 오른쪽: 스톱2만 남아 선을 취득 + 있는 그대로의 나 분단 AoE 회피. 스톱2는 최외곽으로 빔 유도, 다른 멤버는 분단 AoE 회피.

동동코 발구르기 どんどこ地団駄

「있는 그대로의 나」를 시전한 곳을 북쪽으로 삼는다 (이미지에서는 마커 1에서 보크친이 왔으므로 1을 북쪽으로 설정하고 있다).

쉐어 마커(착탄하라)가 붙으므로, 해당 롤은 중앙에서 쉐어로 처리한다.
쉐어가 붙지 않은 롤은 좌우에 2인용 타워가 출현하므로 그것에 들어간다.

이번에는 탱힐이 쉐어를 하고, DPS가 왼쪽 D1·D3 / 오른쪽 D2·D4로 타워에 들어간다.
※ 쉐어와 겹치지 않도록 타워의 살짝 바깥쪽으로 붙는다.

반드시 반대 롤에게 쉐어가 부여되므로, 이번에는 DPS가 중앙에서 쉐어.
왼쪽 MT·H1 / 오른쪽 ST·H2가 타워에 들어간다.
